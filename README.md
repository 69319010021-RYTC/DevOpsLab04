# DevOpsLab04 — FixIT Support

หน้าเว็บต้นแบบสำหรับศูนย์ช่วยเหลือและแจ้งซ่อมอุปกรณ์ IT ช่วยให้พนักงานดูบริการ ขั้นตอนการแจ้งปัญหา และกรอกข้อมูลคำขอซ่อมได้จากหน้าเดียว ออกแบบด้วยโทนสีฟ้า-ขาวที่สบายตา พร้อมรองรับการแสดงผลบนหน้าจอขนาดต่าง ๆ

## ฟังก์ชันและเนื้อหา

- แนะนำบริการซ่อมคอมพิวเตอร์ เครือข่าย และอุปกรณ์สำนักงาน
- แสดงขั้นตอนการแจ้งซ่อมและติดตามสถานะตัวอย่าง
- มีแบบฟอร์มสำหรับกรอกรายละเอียดปัญหา
- ใช้ HTML, CSS และ JavaScript โดยไม่ต้องติดตั้งไลบรารีเพิ่มเติม

> หมายเหตุ: หน้านี้เป็นต้นแบบ แบบฟอร์มยังไม่ได้เชื่อมต่อระบบรับแจ้งซ่อมหรือฐานข้อมูลจริง

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ได้โดยตรง
